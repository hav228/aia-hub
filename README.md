# AIA Lehigh Leaders Hub

Web app for the Athletes in Action ministry at Lehigh: weekly QR check-in and attendance reports, outreach groups and follow-ups, leader and staff schedules with a meeting-time finder, and Sunday study plans.

- **Live site:** https://hav228.github.io/aia-hub/
- **First-time setup:** [SETUP.md](SETUP.md)
- **Running it and handing it off:** [HANDOFF.md](HANDOFF.md)

Built as plain HTML and JavaScript (no build step), with Firebase (Firestore + Google sign-in) for data and GitHub Pages for hosting.
